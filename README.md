# resonance · 共同日记

和几个人一起，把每天的照片、视频和碎碎念，拼成一页属于自己的日记。

---

## 本分支做了什么

一句话：**让日记里的照片按原始比例完整显示，不再被裁剪。**

改动集中在两个样式文件（`src/scrapbook.css`、`src/styles.css`），不涉及数据结构与接口，**已生成的历史日记无需重新生成**。

### 问题

此前日记模板给照片设了固定尺寸，再用 `object-fit: cover` 填满：

| 位置 | 原尺寸设定 |
| --- | --- |
| 手帐相框 | 宽高比固定 4:5 / 1:1 / 4:3 |
| 时间流 | 固定高度 120px |
| 成员分栏 | 固定高度 130px |
| 明信片 | 固定高度 150px |
| 幻灯片 | 固定高度 360 / 430 / 520px |

结果就是**竖图被裁掉左右两侧、横图只露出中间一条**，照片无法完整呈现。

### 改动

统一改为「宽度撑满、高度自适应」：去掉固定宽高比与固定高度，图片按原始比例完整显示，相框和卡片的高度随图片比例自动增长。

覆盖：生活拼贴、秋日手帐、胶片旅行、四季拼贴、时间流、成员分栏、明信片、幻灯片、自定义拼贴，以及历史归档的查看视图。

### 顺带修复

手帐照片在鼠标悬停时会放大 1.025 倍，同样会切掉边缘，现已移除。

## 功能

- **邀请制小组**：创建小组后生成邀请链接，新成员打开链接即可加入；换设备时可用成员识别码恢复身份
- **日常记录**：上传照片、8～60 秒短视频，附一句文字
- **共同日记**：把当天的记录排成一页日记，8 种模板可选，也可自定义板块
- **历史归档**：生成的日记保存到历史，删除后 3 天内可在回收站恢复
- **多人协作**：成员按上传内容自动归类（成员分栏），创建者可移出成员、清空当日记录

## 本地运行

从 GitHub 克隆或下载并解压仓库。Windows 装好 Node.js（20.19+ 的 20.x，或 22.12+）和 Python 3.11 后，双击 **启动.cmd**。首次启动会按项目清单安装前端和后端依赖，之后只在依赖文件更新时重新安装。

浏览器会自动打开 <http://localhost:8010/>。点击「邀请朋友」，程序会用当前网卡的 IPv4 地址生成二维码。手机连同一个可互通的 Wi-Fi 后扫码即可加入。电脑换网后，重启启动器并重新生成二维码；电脑仍用同一个 localhost 地址，浏览器会保留原有身份。

保持启动窗口开启；按 Ctrl+C 可停止服务。找不到可用的 Wi-Fi 或以太网地址时，仍可在电脑上使用，也可以复制链接在本机另一个浏览器打开。

开发模式可运行 `npm run dev`，前端端口为 3002，接口和上传文件由 Vite 代理到 8000。生产构建默认使用页面自己的 `/api`。前后端分开部署时，可在构建前设置 `VITE_API_BASE_URL`。

## 数据与隐私

- 所有照片、视频和数据库都保存在 `backend/` 下（`plog.db`、`uploads/`），可用环境变量 `PLOG_DATA_DIR` 指定其他目录
- 这些运行时数据**不会**进入版本库（已在 `.gitignore` 中排除），备份时请单独复制
- 管理接口目前只做成员 ID 校验，尚未实现完整的登录令牌鉴权，建议仅在受控范围内试用，不要直接暴露到公网

## 已知限制

- HEIC 兼容性与微信 / QQ 内置浏览器的加载速度需要在真机上验证，构建检查无法覆盖
- 幻灯片中过高的竖图会受屏幕高度限制（最多占屏幕高度的 78%～88%）
- 极宽的全景图在双列布局中会被完整但较小地显示
