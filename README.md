# resonance

一页共同日记 · 小组日常记录网站（React + Vite 前端，FastAPI 后端）。

## ✨ 新增功能：生活拼贴（第四版 · 动态排版 + 随机变体）

在「共同日记」卡片点击 tabs 第一个标签 **「生活拼贴」**，标签下方**内联展开设置条**（不再弹窗）：左侧选风格（共 **14 种**，右侧小框实时预览模板）→ 自动读取今日已上传的照片 → 点「立即生成」→ 大图预览 + JPG 下载，还能点「再来一张」换一种排布。纯前端 Canvas 合成，不依赖后端、不需要 AI Key。

**本版新增：**
- **按照片数量动态排版**：1–4 张时从 4 个空位里挑出合适的几个错落摆放，剩余空位自动变成手账便签卡（不留空白相纸框）；5–8 张时把部分空位拆成双图格；超过 8 张取前 8 张并在界面提示。
- **同风格每次生成都不同**：随机种子决定空位组合、照片分配、便签文案和边角手绘点缀；风格美术底图保持一致。点「再来一张」即换新排布。

- 🎨 14 种风格完整提示词：[`docs/拼贴提示词.md`](docs/拼贴提示词.md)

## 快速运行

```bash
npm.cmd install && npm.cmd run build
backend/.venv/Scripts/python.exe -m uvicorn main:app --app-dir backend --host 0.0.0.0 --port 8000
```
打开 http://localhost:8000/

## 功能特点

- **14 种拼贴风格**：INS 极简留白、日系盐系胶片、美式复古杂志、奶油马卡龙、清透 AI 科技磨砂、文艺宣纸书香、街头极简涂鸦、时光日历日记、旅行复古手账、清新绿调手账、四季叙事长卷、波普城市海报、复古蒙太奇、极简风格，每套均带 9:16 竖屏模板图。
- **内联设置条**：入口在 tabs 第一项，展开后选风格 → 右侧预览 → 立即生成，全程不弹窗、不跳页。
- **今日照片自动填入**：直接使用当天已上传的照片，无需重复上传；照片位大、错落倾斜、不裁内容，排版随张数自动变化。
- **随机变体**：同一风格连点「立即生成」会得到不同的空位组合与排布，不会每次都一模一样。
- **纯前端合成**：原生 Canvas，不依赖后端与 AI Key，离线可用；手机 / 电脑浏览器一致体验。
- **轻量无依赖**：不引入任何重型框架，仅用 React + 原生 Canvas。
