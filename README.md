# resonance

一页共同日记 · 小组日常记录网站（React + Vite 前端，FastAPI 后端）。

## ✨ 新增功能：生活拼贴（第二版）

在「共同日记」卡片点击 **🖼️ 生活拼贴**，弹出风格选择面板：先选风格（13 套）→ 选照片数量布局（2/3/4/5 张）→ 上传照片 → 生成 → 预览与 PNG 下载。支持 AI 生成，未配置 AI 时自动用本地离线排版。

- 📖 使用 / 部署 / Git 分支推送完整指南：[`docs/生活拼贴-部署与Git指南.md`](docs/生活拼贴-部署与Git指南.md)
- 🎨 13 套风格 + 4 种布局的完整 AI 提示词：[`docs/拼贴提示词.md`](docs/拼贴提示词.md)

## 快速运行

```bash
npm.cmd install && npm.cmd run build
backend/.venv/Scripts/python.exe -m uvicorn main:app --app-dir backend --host 0.0.0.0 --port 8000
```
打开 http://localhost:8000/

## 功能特点

- **13 套拼贴风格**：INS 极简留白、日系盐系胶片、美式复古杂志、奶油马卡龙、清透 AI 科技磨砂、文艺宣纸书香、街头极简涂鸦、时光日历日记、旅行复古手账、清新绿调手账、四季叙事长卷、波普城市海报、复古蒙太奇，每套均带 9:16 竖屏预览示例图。
- **照片数量布局**：2 张并排 / 3 张错落 / 4 张 2×2 / 5 张叙事，本地 Canvas 与 AI 提示词共用同一套规则。
- **AI 生成 + 本地兜底**：配置 API Key 后调用 AI（风格提示词 + 布局提示词合并发送）；未配置或失败时自动使用纯前端 Canvas 排版，离线也能出图。
- **轻量无依赖**：不引入任何重型框架，仅用 React + 原生 Canvas。
