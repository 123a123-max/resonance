# 生活拼贴 · AI 风格提示词手册

本文档收录「生活拼贴」12 套风格的完整 AI 提示词，与代码 `src/collage/templates.ts` 一一对应。
用途有二：

1. 配置后端 `COLLAGE_AI_API_KEY` 后，前端点击「AI 生成」会自动使用这里的提示词；
2. 也可以复制提示词，到你自己的 AI 绘画工具（Midjourney / Stable Diffusion / 即梦 / 通义万相 / ChatGPT 等）手动生成。

> 通用建议：所有风格都要求「保留真实人脸、高清、干净」。若模型支持负面提示词（Negative prompt），请一并填入。
> 多图融合时，把 2～12 张照片作为参考图 / 垫图一起上传，效果最佳。

```

```
