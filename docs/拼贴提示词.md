# 生活拼贴 · 14 种风格提示词手册

本文档收录「生活拼贴」**14 种风格**的完整提示词，与代码 `src/collage/templateStyles.ts` 一一对应。每条提示词包含基础版式、色调体系、纸张肌理、核心装饰、氛围，以及正向关键词与反向避雷。

用途：① 作为模板设计的规格说明；② 如需接入 AI 出图，可直接把某条提示词作为图像生成 Prompt。模板成图由 `tools/make_*.py` 用免费授权素材合成，照片空位在生成时由前端 Canvas 填入今日照片。

## 1. INS 极简留白高级拼贴

**基础版式**：社交海报版式，构图克制疏朗，整体不拥挤、无冗余元素。
**色调体系**：低饱和莫兰迪色系，米白、浅灰、裸棕为主，无艳丽色彩，色调统一柔和、低对比。
**纸张肌理**：原生柔和哑光纸张纹理，淡淡胶片颗粒，质感细腻平整，无厚重斑驳。
**核心装饰**：少量精简素材（局部人像实拍、风干植物、简约陶瓷器皿），纤细无衬线极小文字，贴纸自带细白描边，元素稀疏、层次轻柔。
**氛围**：松弛、精致、高级、干净极简，时尚轻奢社交风。
**正向**：大量留白、少即是多、高清细腻、层次轻柔、极简克制。
**反向**：色彩浓烈杂乱、元素堆砌拥挤、粗超大字体、密集贴纸、畸形文字、夸张涂鸦、厚重阴影。

## 通用生成约定（所有风格）

1. **画布**：9:16 竖版，900×1600。
2. **照片位要大**：每个模板的照片空位尽量大，不偏小。
3. **摆放随意自由**：错落、倾斜、大小略有差异，随手贴的感觉，不整齐对齐。
4. **照片内容不裁**：模板空位统一用矩形系（撕边/拍立得/圆角/细框/磨砂），保证照片主体不被裁。
5. **素材来源**：Pexels License 与 Wikimedia Commons（Public Domain / CC0 / CC BY），授权来源记录在 `public/assets/collage/*/SOURCES.json`，避开 CC BY-SA 与需署名的商业 IP。
6. **文字**：每张模板配大标题 + 文案，字体/字号/位置按风格定调。
7. **素材与照片的层次**：三种关系可以并存——① 完全独立不碰照片；② 素材压在照片上层一点点（加投影）；③ 照片压住素材边角一点点。唯一红线：只能部分遮挡，不能完整遮挡（素材可见率 > 65%、照片被盖 < 50%）。

## 动态排版与随机变体（前端生成时的通用提示词）

> 这一部分不是画模板底图用的，而是**生成成品拼贴图时**必须遵守的规则，已写进 `templateRenderer.ts`。

```
你是一个生活拼贴生成器。输入：一套风格模板（含 4 个固定照片空位、版权免费素材、大标题与文案）与今天用户上传的 N 张照片。
输出：一张 9:16 竖版成品拼贴图。

【按照片数量排版】
- N = 1：挑一个面积最大的空位放这张照片，让照片尽可能大；其余空位改成手账便签卡（日期 + 手写短句 + 小点缀），不允许留下空白相纸框。
- N = 2：从对角线组合里随机选一组（左上+右下 或 右上+左下）放两张照片，剩下两个空位改成便签卡，错落但不分散。
- N = 3：随机空出一个空位改成便签卡，另外三个放照片。
- N = 4：四个空位全部放照片。
- N = 5~8：四个空位全部使用，并把其中 1~4 个按面积从大到小拆成双图格（横版上下分、竖版左右分，中间留 6px 白缝）以容纳全部照片。
- N > 8：只排前 8 张，并在界面提示用户已截断。

【自由随性】
- 照片用 cover 方式裁切居中，不变形；沿空位原角度倾斜贴入，与模板相纸严格对齐。
- 照片的先后分配做轻度打乱（整体轮转 + 可能交换两张），保留大致时间顺序但每次不同。
- 便签短句从短句池随机取，日期取当天。

【同风格随机变体】
- 每次生成换一个随机种子；种子决定：空位组合、照片分配、便签文案、画面边角 2~4 个手绘点缀（星星/圆圈/短线）的位置与数量。
- 底图美术风格保持不变（这才叫“同一风格”），变化的是排布与点缀，避免每次点击得到一模一样的成品。
- 点缀要克制，不堆砌、不遮挡照片主体与大标题。

【反向避雷】
禁止：固定 4 格硬塞、照片数量不符时留空白相纸框、把第 5 张照片直接丢弃、元素密集堆叠、遮住大标题、改变模板美术风格。
```
